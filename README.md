# Willie Austin

Founder and developer of [theSHFT](https://theshft.app), a private messenger that needs no phone number. I wrote it alone, from the first commit in December 2025 to the App Store in September 2026.

From Selma, Alabama. Computer science, Troy University, 2017. Before software I made clothes under my own label and painted portraits that hang at Troy University.
